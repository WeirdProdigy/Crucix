# v2.13.3 — Biztonsági bejelentések a fork saját címére / Security reports to the fork's own address

## Magyar

### A biztonsági bejelentési cím a fork üzemeltetőjéé

- **Miért:** a [SECURITY.md](../../SECURITY.md) és a GitHub új-issue oldalán megjelenő „Security report” hivatkozás ([.github/ISSUE_TEMPLATE/config.yml](../../.github/ISSUE_TEMPLATE/config.yml)) az eredeti szerző e-mail-címére irányította a sérülékenység-bejelentéseket. Egy forknál ez rossz: a bejelentés olyasvalakihez jutna, aki nem ezt a kódot üzemelteti.
- **A változás:** mindkét helyen az eredeti szerző címe helyett a fork üzemeltetőjének címe áll (`mp3pintyo@gmail.com`). A szövegek többi része, a válaszidő-célok és a hatókör változatlan.
- **Nem változott:** a termék kódja, a tesztek és a dashboard. Szándékosan nem érintettem a `.github/CODEOWNERS` fájlt (`@calesthio`), az OpenRouter-kérés `HTTP-Referer` fejlécét (és az azt ellenőrző tesztet) és a `scripts/collect-upstream.py`-t, mert ezek nem elérhetőségek; külön döntés, ha ezeket is át kell írni.

**Ellenőrzés:** 1420 tesztből 1419 sikeres, 0 hibás, 1 explicit opcionális skip (nincs új teszt, kód nem változott), helyi Node v24.13.0 alatt (`npm test`). `npm run check`: 245 JavaScript-program és a nyelvi ellenőrzés rendben. `npm audit --omit=dev`: 0 sérülékenység. A Node 22-es, a CRLF-es és a böngészős QA-csomagot nem futtattam újra, mert csak két szöveges fájl és a verziószám változott. A repóban követett fájlokban (a kiadási jegyzeteken kívül) már nincs `celesthioailabs` cím.

**Átállás:** nincs teendő, konfiguráció vagy adat nem változott. A PWA shell gyorsítótára változatlanul `crucix-shell-v2.13.0`, mert statikus fájl nem változott.

## English

### Security reports go to the fork's own address

- **Why:** [SECURITY.md](../../SECURITY.md) and the "Security report" link on GitHub's new-issue page ([.github/ISSUE_TEMPLATE/config.yml](../../.github/ISSUE_TEMPLATE/config.yml)) sent vulnerability reports to the original author's e-mail address. For a fork that is wrong: a report would reach someone who does not run this code.
- **The change:** both places now show the fork operator's address (`mp3pintyo@gmail.com`) instead of the original author's. The rest of the text, the response targets and the scope are unchanged.
- **Unchanged:** the product code, the tests and the dashboard. I deliberately left `.github/CODEOWNERS` (`@calesthio`), the OpenRouter request's `HTTP-Referer` header (and the test that checks it) and `scripts/collect-upstream.py` alone, because those are not contact details; changing them is a separate decision.

**Validation:** 1419 of 1420 tests passed, 0 failed, 1 explicit optional skip (no new test, no code changed), on the local Node v24.13.0 (`npm test`). `npm run check`: 245 JavaScript programs and the locale check pass. `npm audit --omit=dev`: 0 vulnerabilities. I did not re-run the Node 22 suite, the CRLF suite or the browser QA, because only two text files and the version number changed. No tracked file (outside the release notes) contains the `celesthioailabs` address any more.

**Upgrade:** nothing to do, no configuration or data changed. The PWA shell cache stays at `crucix-shell-v2.13.0` because no static asset changed.
