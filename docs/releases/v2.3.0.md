# Crucix 2.3.0 — Használhatóbb felület és teljes audit / Dashboard usability and full audit

## Magyar

- 13 logikai réteg közös kapcsolása a síktérképen és a valódi WebGL földgömbön, beleértve az USGS földrengéseket. A rétegek és panelbeállítások mentődnek; tiltott localStorage mellett is működik a felület.
- Új forrásállapot-panel: elérhető, hibás, kikapcsolt és elavult adat külön állapottal. A kapcsolat, snapshot-kor és OpenSky cache külön látható; az élő kapcsolat nem jelenti automatikusan, hogy az adat friss.
- Akadálymentes beállítások: fókuszcsapda, Escape, háttér inert, fókusz visszaállítása, Alt+fel/le rendezés és választható panelzóna. Magyar/angol/francia szöveg és 390px mobil ellenőrzés. Reduced-motion kikapcsolja az automatikus globe-forgást.
- Szabály-/modellötletek eredet- és cache-korjelzése, üres és első adatra váró állapot. Hiányzó Treasury nem szakítja meg a panelépítést; üres sugárzáslista nem állítja, hogy minden helyszín normális.
- Egyetlen SSE natív újracsatlakozással, határolt polling fallbackkel és API-shape ellenőrzéssel. Hibás vagy késve beérő régebbi válasz nem írja felül a frissebb érvényes adatot. Országfeliratok megmaradnak pan/zoom alatt.
- GDELT érvénytelen naptári napja nem normalizálódik valótlan időpontra. Maritime kulcsbeállítás nem ígér automatikus élő AIS-kapcsolatot.
- Publikált teljes kódaudit, egyedi döntés mind a **104 upstream PR-ról és 50 issue-ról**, diff-hashok és végső integrációs státusz. 58 tétel megvalósított, 8 hasznos része adaptált; más tételek már jelen voltak, duplikáltak, opcionálisak, elutasítottak vagy környezetfüggők. A #27 obfuszkált kódja teljes egészében kizárva.
- Elsődleges dokumentációra épülő World Monitor/NEXUsint összevetés, fejlesztési prioritások, architektúra ábra és LAN/Docker/forrás/helyimodell üzemeltetési útmutató. Groq generic compatible endpoint konfigurálás, külön SDK nélkül.

**Ellenőrzés:** 132 tesztből 131 sikeres, 1 opcionális élő API-teszt kihagyva; JavaScript-szintaxis és locale JSON érvényes; production dependency audit: 0 ismert sérülékenység. Chromium asztali/mobil QA: rétegek, WebGL, billentyűzet, mentés, hostile text, üres/hibás adat, blocked storage, SSE reconnect és fallback polling. A [QA-jegyzőkönyv](../audit/browser-qa-2026-10-01.md) rögzíti a részleteket; a GitHub CI Node 22/24 Windows/Linux és non-root multiarch Docker buildet futtat.

**Átállás:** a meglévő magyar felület, IODA/WHO/HDX és panelbeállítások megmaradnak. A rétegek új beállításai alapból bekapcsoltak. A régi layout automatikusan megkapja az új source-health panelt. Éles modellek/botok és minden külső feed működése szolgáltató- és konfigurációfüggő; az audit nem adott minden PR-forkhoz runtime igazolást. Opcionális új funkciók indoklása a [döntési jelentésben](../audit/upstream-review-2026-10-01.md) olvasható.

**GitHub-igazolás:** a `9ad10f8` kiadási commit [CI-futása](https://github.com/mp3pintyo/Crucix/actions/runs/36909652111) sikeres: négy Windows/Linux × Node22/24 job, non-root írási smoke és linux/amd64 + linux/arm64 build/publikálás.

## English

- Added 13 shared logical layer switches for the flat map and real WebGL globe, including USGS earthquakes. Layer and panel preferences persist; blocked localStorage does not prevent startup.
- Added distinct available/error/disabled/stale source states, separate connection and snapshot freshness, and visible OpenSky cache age. A live connection no longer implies fresh observations.
- Accessible settings support focus trapping, Escape, inert background, restored focus, Alt+Up/Down ordering and zone selection. English/French/Hungarian copy and 390px mobile checks; reduced motion disables automatic globe rotation.
- Ideas identify rules/model origin and cached age. Empty and first-snapshot waiting states are explicit. Missing Treasury data no longer aborts rendering; empty radiation data cannot imply all sites are normal.
- One EventSource uses native reconnection with bounded fallback polling and validated API payloads. Invalid or delayed older responses preserve the newer valid snapshot. Country labels remain visible during map pan/zoom.
- Invalid GDELT calendar dates and compact 24:00 timestamps are rejected rather than silently normalized. Maritime key configuration does not claim an automatic live AIS connection.
- Published the full code review and individual decisions for **104 upstream PRs and 50 issues**, including diff hashes and final integration outcomes: 58 implemented items, 8 selectively adapted items, and explicit existing/duplicate/optional/rejected/environmental decisions. Obfuscated code in PR #27 was excluded entirely.
- Added a primary-source World Monitor/NEXUsint comparison, ranked next features, current architecture diagram and source/LAN/Docker/local-model operations guide, including Groq through the generic compatible endpoint.

**Validation:** 131/132 tests passed, one optional live integration skipped; JavaScript and locale checks passed; zero known production dependency vulnerabilities. Desktop/mobile Chromium QA covers layers, WebGL, keyboard controls, persistence, hostile text, empty/malformed data, blocked storage, SSE reconnection and polling fallback. See the [QA report](../audit/browser-qa-2026-10-01.md). GitHub CI runs Windows/Linux Node 22/24 and a non-root multiarch Docker build.

**Migration:** existing Hungarian UI, IODA/WHO/HDX and panel preferences are preserved. New layers default to enabled; saved layouts gain the source-health panel automatically. Live providers/bots and external feeds remain configuration-specific. Large alternative PR forks were not runtime-certified; deferred and rejected items have individual explanations in the [decision report](../audit/upstream-review-2026-10-01.md).

**GitHub evidence:** the release commit `9ad10f8` passed [CI](https://github.com/mp3pintyo/Crucix/actions/runs/36909652111): all four Windows/Linux × Node22/24 jobs, non-root write smoke check and linux/amd64 + linux/arm64 build/publication.
