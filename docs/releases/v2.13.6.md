# v2.13.6 — CI-javítás: a v2.13.5 egyik oldal-tesztje / CI fix: a page test of v2.13.5

## Magyar

### A v2.13.5 CI-ja piros lett, ez a javítása

- **Mi történt:** a v2.13.5-ben a `connectSSE` az új `hasSnapshot` segédfüggvényt hívja ([jarvis.html](../../dashboard/public/jarvis.html)). A [test/replay.test.mjs](../../test/replay.test.mjs) az oldal néhány függvényét név szerint emeli ki egy külön környezetbe, és ebből hiányzott a `hasSnapshot` (`hasSnapshot is not defined`). A termék kódja helyes volt, a teszt kiemelési listája nem. A helyi, célzott futás ezt a fájlt nem tartalmazta, ezért csak a CI vette észre; a tag-futás piros volt, ezért a v2.13.5 Docker-képe nem készült el.
- **Javítás:** a `hasSnapshot` bekerült a kiemelt függvények listájába. Más nem változott; a v2.13.5 összes változtatása (SSE-megszakadás javítása, Codex-modell követése) változatlanul ebben a kiadásban él.
- **Ellenőrzés:** az összes, a `jarvis.html`-t olvasó tesztfájl (11 fájl) lefutott: 313 teszt, 0 hibás.

**Átállás:** a v2.13.5 átállási lépései érvényesek (szerver újraindítása, böngészőlap frissítése); ez a kiadás a v2.13.5 helyett használandó.

## English

### The v2.13.5 CI went red; this fixes it

- **What happened:** in v2.13.5 `connectSSE` calls the new `hasSnapshot` helper ([jarvis.html](../../dashboard/public/jarvis.html)). [test/replay.test.mjs](../../test/replay.test.mjs) lifts some of the page's functions by name into a separate context, and `hasSnapshot` was missing from that list (`hasSnapshot is not defined`). The product code was right, the test's lift list was not. My local targeted run did not include this file, so only CI caught it; the tag run was red, so no Docker image was built for v2.13.5.
- **Fix:** `hasSnapshot` is now in the list of lifted functions. Nothing else changed; every change of v2.13.5 (the SSE cut fix, following the Codex model) lives on unchanged in this release.
- **Validation:** every test file that reads `jarvis.html` (11 files) ran: 313 tests, 0 failed.

**Upgrade:** the v2.13.5 upgrade steps apply (restart the server, reload the browser tab); use this release instead of v2.13.5.
