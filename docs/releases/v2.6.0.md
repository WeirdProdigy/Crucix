# Crucix 2.6.0 — Mentett munkaterületek és PWA / Saved workspaces and PWA

## Magyar

- Kutatás, piac és infrastruktúra panelprofilok; legfeljebb 12 saját, elnevezhető, átnevezhető és törölhető profil. Panelrendezés, térképrétegek és régió együtt menthető. A korábbi egyéni nézet visszaállítható, tiltott localStorage mellett munkameneten belüli mentés működik.
- Telepíthető PWA manifesttel és ikonokkal. A térkép, földgömb, fontok, programok és textúrák helyi, verziózott fájlokból töltődnek. 27 vendor asset licence és SHA-256/byte jegyzéke ellenőrzött; a konténer CI ezt is ellenőrzi.
- Adatmentes offline kezdőfelület és külön, alapból kikapcsolt IndexedDB snapshotmentés. Engedélyezés után hálózat nélküli újratöltéskor az utolsó érvényes adat látható gyűjtési idővel és mentett/offline jelzéssel. Törlés a következő mentést is letiltja. Hibás, túlméretes és jövőbeli cache nem akadályozza a friss mentést.
- A service worker csak engedélyezett statikus fájlokat és üres shellt cache-el. Élő injektált HTML, API, SSE és hitelesítési fejléc nem kerül a cache-be; 401/403 nem változik offline sikernek. Új verzió csak kifejezett frissítésre tölti újra az oldalt.
- Billentyűzetes/mobil profil- és PWA-kezelés, fókusz-visszaállítás, tárolási hiba esetén látható üzenet és visszaállított kapcsoló. Magyar, angol és francia felület.

**Használat:** egyszer nyisd meg a futó szervert `http://localhost:3117` címen, majd a böngésző telepítési menüjével vagy a támogatott PWA-telepítési gombbal telepítsd. LAN-on HTTPS szükséges a service workerhez. Az offline shell automatikus, az eseményadatok mentését a PWA-beállításokban külön engedélyezd. A friss adatgyűjtéshez és a szerveroldali történet/export eléréséhez továbbra is szerver/hálózat szükséges. A mentés böngészőprofilhoz és originhez kötött. A kérés szerint nincs külön Tauri/Windows wrapper.

**Ellenőrzés:** 225 tesztből 224 sikeres, 1 explicit opcionális skip, 0 hiba; 121 JavaScript-program és locale ellenőrizve, production audit: 0 ismert sérülékenység. Valódi Chromium offline reload mentett és törölt adatokkal, helyi flat/globe térkép, tiltott IndexedDB/localStorage, mobil HU/EN/FR részletező, profilváltás/újratöltés, JSON/CSV/STIX és valódi PDF, valamint a korábbi WebGL/réteg/SSE/polling regressziók sikeresek. Élő botot/modellt nem hívtunk a tesztekben. A kiadás CI eredménye a [verifikációs jegyzőkönyvben](../audit/intelligence-workspace-verification.md) követhető.

## English

- Research, Market and Infrastructure presets plus up to 12 named custom profiles with rename/delete. Profiles save panel layout, map layers and region together. The previous custom view remains restorable; blocked localStorage uses session-only persistence.
- Installable PWA with manifest/icons. Maps, globe, fonts, scripts and textures load from pinned local files. All 27 vendor assets carry licence records and SHA-256/byte verification, also checked inside the CI container.
- An empty offline shell and separate, disabled-by-default IndexedDB snapshot saving. Once enabled, offline reload restores valid last data with its collection time and saved/offline label. Clearing disables subsequent saves. Corrupt, oversized or future-dated entries cannot block a fresh save.
- Service worker caching is restricted to allowlisted static assets and the empty shell. Live injected HTML, APIs, SSE and authentication headers are excluded; 401/403 remain authentication failures. Updates reload only after explicit user action.
- Keyboard/mobile profile and PWA controls, restored focus, visible storage failures and checkbox rollback. English, Hungarian and French translations.

**Usage:** first open the running server at `http://localhost:3117`, then install through the browser menu or the supported PWA button. LAN service workers require HTTPS. The static offline shell is automatic; opt in separately to saving event data. New collection and server history/exports require the server/network. Saved snapshots belong to the browser profile and origin. As requested, no Tauri/native Windows wrapper is included.

**Validation:** 224 tests pass, one explicit optional test is skipped, zero fail; 121 JavaScript programs/locales verified and no known production dependency vulnerability. Real Chromium covers offline reload with saved/cleared data, local flat/globe maps, denied IndexedDB/localStorage, HU/EN/FR mobile details, profile persistence/restoration, real JSON/CSV/STIX downloads and PDF, plus existing WebGL/layer/SSE/polling regressions. Tests do not call live bots/models. Release CI is recorded in the [verification report](../audit/intelligence-workspace-verification.md).
