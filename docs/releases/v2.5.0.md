# Crucix 2.5.0 — Kereshető történet és export / Searchable history and export

## Magyar

- Tartós eseménytörténet, ékezetfüggetlen szöveges keresés, típus/forrás/UTC gyűjtési idő szerinti szűrés, lapozás és a teljes szűrt találathalmaz idővonala.
- JSON, CSV, nyomtatható HTML/PDF és STIX 2.1 export. Az export a szűrést megtartja, legfeljebb 2000 rekordot ad, és jelzi a csonkolást. PDF a böngésző Nyomtatás → Mentés PDF-ként funkciójával készül. A STIX jelentések és jegyzetek általános eseményeket írnak le, nem állítanak kitalált kiberfenyegetést.
- Választható térképes hírcsoportosítás a sík- és földgömbnézetben. Csak ismert szolgáltatói idővel és helyadattal rendelkező közeli hír-/OSINT-események kerülnek közös térbeli/időbeli cellába; az eredeti események külön megnyithatók.
- Atomi mentés és használható biztonsági másolatból visszaállítás. 30 nap / 10 000 rekord / 20 MiB korlát. Az első és utolsó gyűjtési idő megmarad, régebbi válasz nem írja vissza az adatot. Az azonosító és forrás-URL ütközése egyesül; jövőbeli hibás elsődleges fájl nem törli a jó backupot.
- Minden API a meglévő hitelesítés alatt, no-store válasszal működik. Ellenőrzött szűrők és eseményazonosítók; veszélyes HTML, CSV-képlet és hitelesítő adatot tartalmazó forráslink sem kerül aktív tartalomként az exportba.

**Átállás:** az előzmény a `runs/intelligence/history.json` fájlba kerül, a meglévő raw archívumok változatlanok. Induláskor az utolsó snapshot és az ezután gyűjtött események kerülnek az új naplóba; régi archívumok tömeges visszatöltése nem történik. A keresés/export eléréséhez futó helyi szerver szükséges.

**Ellenőrzés:** 219 tesztből 218 sikeres, 1 opcionális skip; szintaxis/locale, production audit és whitespace sikeres. Valódi böngészős JSON/CSV/STIX letöltés és parse, szűrők megőrzése, HTML riport és tényleges Chromium PDF, történeti lapozás, flat/globe csoportnyitás és rétegkapcsolás sikeres.

## English

- Added persistent event history with accent-insensitive literal search, type/source/UTC collection-date filters, pagination and a timeline covering all filtered matches.
- Added JSON, CSV, printable HTML/PDF and STIX 2.1 exports preserving filters. Exports are capped at 2,000 records with visible truncation; PDF uses browser Print → Save as PDF. STIX reports/notes describe events without inventing cyber-threat indicators.
- Optional spatial/time news grouping works on flat/globe maps. Groups require known provider time and location; original news/OSINT events remain individually inspectable.
- Atomic journal and validated-backup recovery: 30 days / 10,000 records / 20 MiB. First/last collection times remain monotonic, ID/URL collisions coalesce, and corrupt future-dated primary data cannot erase a usable backup.
- Existing authentication protects every history/event/export API with no-store responses. Filters and IDs are validated; HTML payloads, CSV formulas and credential-bearing source URLs remain inert or are rejected.

**Migration:** history lives in `runs/intelligence/history.json`. Existing raw archives are preserved. The latest snapshot and subsequent sweeps seed the new journal; old archives are not bulk re-imported. Searching/exporting requires the running local server.

**Validation:** 218 tests pass and one optional test is skipped; syntax/locales, production audit and whitespace checks pass. Real JSON/CSV/STIX browser downloads parse successfully with filters retained. HTML reporting and actual Chromium PDF output, pagination, physical flat/globe group clicks and layer switches pass.
