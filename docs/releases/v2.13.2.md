# v2.13.2 — README: a kapcsolat és a Star History szakasz eltávolítva / README: Contact and Star History sections removed

## Magyar

### Az eredeti projekt elérhetőségei és csillagdiagramja kikerült a README-ből

- **Miért:** a „Contact” szakasz az eredeti szerző e-mail-címét tartalmazta, a „Star History” diagram pedig az eredeti `calesthio/Crucix` repó csillagait mutatta. Egyik sem ennek a forknak a címe vagy adata, a v2.13.1-ben eltávolított demó- és közösségi hivatkozásokhoz hasonlóan.
- **Eltávolítva a [README.md](../../README.md)-ből:** a teljes „Contact” és „Star History” szakasz (a szerzői e-mail-cím, a GitHub Issues-re hivatkozó mondat és a `star-history.com` képek). A „Contributing” és a „License” szakasz között egy elválasztó marad.
- **Nem változott:** a termék kódja, a tesztek, a dashboard és a README többi része. A hibajelentések a `CONTRIBUTING.md`-ben és a `SECURITY.md`-ben leírt úton mennek tovább.

**Ellenőrzés:** 1420 tesztből 1419 sikeres, 0 hibás, 1 explicit opcionális skip (nincs új teszt, kód nem változott), helyi Node v24.13.0 alatt (`npm test`). `npm run check`: 245 JavaScript-program és a nyelvi ellenőrzés rendben. `npm audit --omit=dev`: 0 sérülékenység. A Node 22-es, a CRLF-es és a böngészős QA-csomagot nem futtattam újra, mert ebben a kiadásban csak a README és a verziószám változott. A GitHub CI a `check`, a `test` és az `npm audit` lépést futtatja.

**GitHub CI:** a branch- és a tag-push is magától indította a CI-t, mindkettő sikeres (`quality` leg-ek és GHCR Docker-build/publikálás): [master-futás](https://github.com/mp3pintyo/Crucix/actions/runs/37452000115) és [tag-futás](https://github.com/mp3pintyo/Crucix/actions/runs/37452003178).

**Átállás:** nincs teendő, konfiguráció vagy adat nem változott. A PWA shell gyorsítótára változatlanul `crucix-shell-v2.13.0`, mert statikus fájl nem változott.

## English

### The original project's contact details and star chart are gone from the README

- **Why:** the "Contact" section held the original author's e-mail address and the "Star History" chart showed the stars of the original `calesthio/Crucix` repository. Neither is this fork's address or data, like the demo and community links removed in v2.13.1.
- **Removed from [README.md](../../README.md):** the whole "Contact" and "Star History" sections (the author's e-mail address, the sentence pointing to GitHub Issues and the `star-history.com` images). One divider remains between "Contributing" and "License".
- **Unchanged:** the product code, the tests, the dashboard and the rest of the README. Bug reports keep going the way `CONTRIBUTING.md` and `SECURITY.md` describe.

**Validation:** 1419 of 1420 tests passed, 0 failed, 1 explicit optional skip (no new test, no code changed), on the local Node v24.13.0 (`npm test`). `npm run check`: 245 JavaScript programs and the locale check pass. `npm audit --omit=dev`: 0 vulnerabilities. I did not re-run the Node 22 suite, the CRLF suite or the browser QA, because this release changes only the README and the version number. GitHub CI runs `check`, `test` and `npm audit`.

**GitHub CI:** both the branch push and the tag push started CI on their own and both succeeded (`quality` legs and the GHCR Docker build/publish): the [master run](https://github.com/mp3pintyo/Crucix/actions/runs/37452000115) and the [tag run](https://github.com/mp3pintyo/Crucix/actions/runs/37452003178).

**Upgrade:** nothing to do, no configuration or data changed. The PWA shell cache stays at `crucix-shell-v2.13.0` because no static asset changed.
