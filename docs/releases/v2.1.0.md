# Crucix 2.1.0 — Biztonság és üzemeltetés / Security and operations

## Magyar

- Javítottuk a külső hírekből, SDR-nevekből és LLM-válaszokból származó HTML/script injekciót. Az inline JSON minden `<` karaktert escape-el; a panelmezők és linkattribútumok kódoltak, a popup szövegként jelenik meg.
- A Discord vezérlőparancsok csatorna-, szerver- és jogosultságellenőrzést kaptak. A némítás ideje korlátozott.
- A Telegram OSINT-forrás többé nem olvas privát botüzeneteket. A nyilvános előnézetek gyűjtése külön bekapcsolható. Az ACLED debug napló nem ír hitelesítési tokent vagy cookie-t.
- Localhost alapértelmezés, választható HTTP Basic védelem, `PUBLIC_URL`, érvényesített port/env-beállítások, shell nélküli böngészőnyitás, korlátos SSE és heartbeat.
- Reprodukálható `npm ci`, nem root Docker-folyamat, dinamikus healthcheck, SHA-hoz kötött CI actionök és automatikus ellenőrzés. A függőségaudit 4 ismert sérülékenységről 0-ra csökkent.

**Ellenőrzés:** 79 JavaScript-program szintaxisellenőrzése; 58 tesztből 57 sikeres, 1 opcionális élő API-teszt kihagyva; `npm audit --omit=dev`: 0 sérülékenység; `git diff --check` sikeres. Valódi HTTP- és szerverindítási tesztek, célzott HTML/Discord/Telegram regressziók.

**Beállításváltozás:** LAN-hoz `HOST=0.0.0.0`, Compose-hoz `BIND_ADDRESS=0.0.0.0` kell. Nyilvános Telegram-forrás: `TELEGRAM_OSINT_ENABLED=true`. Linux bind mount esetén a `runs` könyvtárnak írhatónak kell lennie UID 1000 számára. Távoli Basic hitelesítéshez HTTPS proxy szükséges. A helyi Docker daemon nem futott; a konténer buildjét a GitHub Actions ellenőrzi. Élő bot/provider szolgáltatást nem teszteltünk.

## English

- Fixed HTML/script injection through external headlines, SDR names and model output. Inline JSON escapes every `<`; panel fields and link attributes are encoded, and popup content uses text rendering.
- Discord controls now enforce channel, guild and user permissions, with bounded mute duration.
- Telegram OSINT no longer reads private/control bot updates. Public preview collection requires explicit opt-in. ACLED diagnostics no longer log tokens or cookies.
- Added localhost defaults, optional HTTP Basic protection, `PUBLIC_URL`, validated ports/env values, browser launch without a shell, bounded SSE connections and heartbeats.
- Added reproducible `npm ci`, non-root Docker execution, a port-aware healthcheck, pinned CI actions and automatic checks. Dependency audit reduced four known vulnerabilities to zero.

**Validation:** syntax checked 79 JavaScript programs; 57/58 tests passed with one optional live integration skipped; production dependency audit reports zero vulnerabilities; whitespace checks passed. Includes real HTTP/server-start and targeted HTML/Discord/Telegram regression tests.

**Migration:** use `HOST=0.0.0.0` for native LAN access or `BIND_ADDRESS=0.0.0.0` in Compose. Opt in with `TELEGRAM_OSINT_ENABLED=true`. Linux bind mounts must be writable by UID 1000. Use HTTPS for remote Basic authentication. Local Docker daemon was unavailable; GitHub Actions builds the image. Live bot/provider services were not exercised.
