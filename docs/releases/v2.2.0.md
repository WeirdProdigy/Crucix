# Crucix 2.2.0 — Megbízható adatok és helyi AI / Reliable data and local AI

## Magyar

- A hálózati határidő a teljes választestre érvényes; korlátos válaszméret, garantált cleanup, HTTP 429 és numerikus/HTTP-date Retry-After kezelés. Nem retry-zunk hitelesítési hibát, és nem írunk ki titkot visszhangzó upstream body-t.
- OFAC: két, legfeljebb 64 KiB-os exportminta, Range-et figyelmen kívül hagyó szervernél is megszakított stream; valós publikálási dátum és egyértelmű partial/sample metaadat. NOAA: a nem támogatott limit elhagyása, külön hibás és valóban üres állapot.
- 31 forrásadapter: új USGS significant-day földrengésadat, Arctic hajózási referenciapontok. A tsunami flag nem hatósági riasztás; a Maritime adapter nem állít nem létező élő AIS-kapcsolatot.
- Forráshibák, tiltott és stale állapotok helyes számlálása; EPA/Safecast elégtelen mérésből nem jelent normális sugárzást. Yahoo hibánál megmarad a műszer neve/szimbóluma.
- OpenSky: legfeljebb egyórás, érvényes időbélyegű fallback, a sikeres friss részadatok megőrzésével. Stabil, jelölt hírkoordináták; hely nélküli hírek megmaradnak a tickerben; GDELT nem kap mesterséges „most” dátumot; BBC HTTPS.
- Egységes, normalizált LLM-ötletek és riasztásválaszok, magyar/angol rules fallback, helyes delta mezők, Gemini thinking rész kihagyása, valódi token/időkeret. Keyless OpenAI-compatible adapter llama.cpp/LM Studio számára.
- Ritkítható ötletgenerálás az eredeti cache-idő megtartásával; a delta-riasztások továbbra is minden sweepben futnak. Discord LLM-ötletriasztások korláttal, deduppal és mute tiszteletben tartásával.
- Atomi snapshot-mentés, nyolc saját előzmény, gyors hálózatmentes warm-load; korábbi ötletek helyes megőrzése, health/metals delta összehasonlítás és sérült hot-memory backup-visszaállítás.
- Node 22/24 Windows/Linux CI, nem root konténer írási smoke check, külső hálózattól elzárt szerverindítási regresszió.

**Ellenőrzés:** 132 tesztből 131 sikeres, 1 opcionális élő API-teszt kihagyva; 96 JavaScript-program szintaxisa és locale JSON érvényes; production audit: 0 ismert sérülékenység; whitespace ellenőrzés sikeres. A PR/issue pillanatkép mind a 104 PR-t és 50 issue-t lefedi; részletes döntéslista a következő UX/audit kiadásban.

**Beállítások:** `LLM_PROVIDER=openai-compatible`, `LLM_BASE_URL`, a négy `LLM_*_MAX_TOKENS`/`LLM_*_TIMEOUT_MS` és `LLM_IDEAS_EVERY_N_SWEEPS`. Alapértékek kompatibilisek; érvénytelen érték startupkor hibát ad. A Codex subscription adapter timeoutja korlátos, a token capet a jelenlegi endpoint adapter nem küldi. A külső bot/provider szolgáltatásokat mintaválaszokkal, nem éles kulcsokkal teszteltük.

## English

- Network deadlines now include body reading, with bounded sizes, cleanup, 429/Retry-After handling and no retries for authentication errors. Error bodies that may echo secrets are omitted.
- OFAC uses two bounded 64 KiB samples even when Range is ignored, with honest partial/count metadata. NOAA removes the unsupported limit and distinguishes upstream failures from genuinely empty alerts.
- Added the keyless USGS significant-day feed and Arctic reference chokepoints, bringing the registry to 31 adapters. Tsunami flags are not issued warnings; reference Maritime data does not claim a live AIS connection.
- Correct failure/disabled/stale accounting; insufficient EPA/Safecast readings cannot imply normal radiation. Yahoo errors retain instrument identity.
- OpenSky fallback expires after one hour and preserves healthy current regions. News coordinates are stable and inferred; unlocated articles stay in the feed. GDELT preserves provider time; BBC feeds use HTTPS.
- Normalized ideas and alert schemas, English/Hungarian rule fallback, correct delta fields, Gemini thinking filtering, bounded model requests, and a separate keyless OpenAI-compatible local provider.
- Configurable idea cadence preserves cache age while delta alerts run every sweep. Discord idea alerts enforce caps, deduplication, mute and priority limits.
- Atomic snapshots, eight owned history files, fast offline warm-load, correct prior-idea ordering, persisted health/metals comparisons and corrupted-memory backup recovery.
- Added Windows/Linux Node 22/24 CI and non-root container write verification; startup regressions deny external network requests.

**Validation:** 131/132 tests passed, one optional live integration skipped; 96 JavaScript programs and locale JSON checked; zero known production dependency vulnerabilities; whitespace checks passed. All 104 upstream PRs and 50 issues were individually assessed; the complete report accompanies the next UX/audit release.

**Configuration:** use `LLM_PROVIDER=openai-compatible`, `LLM_BASE_URL`, the four model budget variables, and `LLM_IDEAS_EVERY_N_SWEEPS`. Defaults preserve existing cadence/budgets; invalid settings fail at startup. The Codex subscription adapter enforces timeout but does not send an output-token cap. Live bot/provider behavior remains service-specific; tests used mocks and local fixtures.
